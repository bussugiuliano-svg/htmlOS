questo è un sistema operativo simulato chiamato "htmlOS", simula un ambiente desktop stile windows vista/windows 8, è stato generato interamente da claude sonnet 5.5 di anthropic, comprese le esstensioni che verranno pubblicate qui, per usarlo basterà scaricare il file "htmlOS" ed eseguirlo in un qualsiasi browser, non necessita di nessun tipo di dipendenza, e se possibile si collegherà a questa directory di github per poter scaricare pacchetti di aggiornamento (solo quando l'app "Package Browser" viene aperta). Sconsiglio agli utenti di caricare file importanti, poichè l'OS non è ne una cassaforte e ne un sistema testato da esperti, e nel caso sconsiglio nuovamente di scaricare molti pacchetti perché sono ancora meno testati, consiglierei di installarli solo se qualcuno li ha già provati prima ed ha gradito (tramite recensioni).
