questo è un sistema operativo simulato chiamato "htmlOS", simula un ambiente desktop stile windows vista/windows 8, è stato generato interamente da claude sonnet 5.5 di anthropic, comprese le esstensioni che verranno pubblicate qui, per usarlo basterà scaricare il file "htmlOS" ed eseguirlo in un qualsiasi browser, non necessita di nessun tipo di dipendenza, e se possibile si collegherà a questa directory di github per poter scaricare pacchetti di aggiornamento (solo quando l'app "Package Browser" viene aperta).
