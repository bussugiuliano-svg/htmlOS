# htmlOS
è la repository ufficiale di un OS simulato chiamato "htmlOS", qui vengono pubblicati gli aggiornamenti, app, temi, funzionalità... ed il file html dell'OS stesso. (l'intero htmlOS è stato generato da claude sonnet 5.5, lo dichiaro esplicitamente per trasparenza, insieme alla maggior parte delle estensioni che verranno pubblicate)
